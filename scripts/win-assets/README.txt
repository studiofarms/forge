FRAMEFORGE FOR WINDOWS
======================

INSTALL (recommended)
  1. Extract this whole zip anywhere (right-click -> Extract All).
  2. Double-click "Install FrameForge.cmd".
     If Windows SmartScreen appears: More info -> Run anyway.
  3. FrameForge installs to your programs folder, puts shortcuts on
     the Desktop and Start Menu, and launches.

OR RUN WITHOUT INSTALLING
  Open the FrameForge folder and double-click FrameForge.exe.

FIRST STEPS IN THE APP
  A test GPU is built in. Go to Connect, paste:
      http://127.0.0.1:8188
  and press Connect. Then: Brand Kits -> add your logo/photos,
  Content Packs -> Queue renders, and watch the Gallery fill with
  placeholder clips (~6 seconds each).

REAL AI VIDEO (still free)
  Run backend/kaggle_notebook.py from the project on kaggle.com
  (free GPU notebook, ~6 min to boot) and paste the URL it prints
  into Connect instead of the test address.

UNINSTALL
  Double-click "Uninstall FrameForge.cmd".
